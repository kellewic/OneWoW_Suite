# OneWoW_CatDB_Other

Unassigned Catalog rows (items, NPCs, quests, places) that do not yet belong to an expansion.

The Distro zip always includes this addon. In Manage Features it shows as **Other**. Items and achievements are on by default; other topics stay off until you turn them on.

When we can name an expansion, those rows move there. They do not fall back to Other after that.
